# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Unity 2022.3.62f3 project. This is `shashwahpple/daggerfall-unity-android`, an unofficial Android port of
[Daggerfall Unity](https://github.com/Interkarma/daggerfall-unity) (`upstream` remote). `origin` is this fork.

- `Assets/Scripts/` — the shared Daggerfall Unity codebase (namespace `DaggerfallWorkshop...`), organized into
  `API`, `Game`, `Internal`, `Editor`, `Utility`, `Terrain`, `Localization`, `External`.
- `Assets/Android/` (`Scripts/`, `Editor/`, `Prefabs/`, `Text/`, `Textures/`) and `Assets/Plugins/Android/` —
  Android-fork-specific code and manifest. Check here first for anything Android-related before assuming a
  change belongs in the shared `Assets/Scripts/` tree.

Android/Discord issues belong on this fork's issue tracker, not upstream's.

## Build & verify

There is no CLI build, no automated test suite, and no CI in this repo — Unity builds happen manually in the
Editor. Do not invent npm/cargo-style build or test commands.

- Android builds go through **Daggerfall Tools → Android → Multi-Build Tool** in the Unity Editor
  (`Assets/Android/Editor/AndroidBuildTool.cs`) — supports armv7/arm64, IL2CPP, dev builds, per-config
  enable/disable.
- The standard way to verify a change is building and running it on a device or emulator (or Editor Play Mode
  for quick, non-Android-specific checks). Say explicitly when a change hasn't been build-tested rather than
  claiming it works.

## Code style

- 4-space indentation, LF line endings, UTF-8, trim trailing whitespace (`.editorconfig`, applies repo-wide).
- PascalCase for classes/methods/properties, per existing convention.
- Original upstream Daggerfall Unity files carry a standard header block (Project/Copyright/Web
  Site/License: MIT/Source Code/Original Author/Contributors/Notes). This is upstream boilerplate — do **not**
  add it to new Android-fork-authored files; none of the existing fork-only files (e.g. under `Assets/Android/`)
  carry it.
- `.editorconfig` also has C# analyzer/naming rules that IDEs and `dotnet format` pick up via the generated
  `.csproj` files (gitignored, regenerated by Unity — Edit → Preferences → External Tools → set an installed
  external editor (e.g. VS Code) → Regenerate project files). Run `dotnet format Assembly-CSharp.csproj
  --verify-no-changes` to lint the main game assembly.

## Git

- Commit messages: short imperative summary line (e.g. "Fixed black screen on fresh install", "Add progress UI
  and async error handling for mod imports"), optionally with a `*`-bulleted body for multi-part changes.
- Default workflow is committing directly to the `android` branch on this fork — no feature-branch/PR
  requirement.

## Android gotchas

- Scoped storage / "all files access" permissions are a recurring pain point — see `AndroidUtils.cs`,
  `ModLoaderInterfaceWindow.cs`, `SaveLoadManager.cs`.
- Mods (`.dfmod`) are validated for Android-compatible asset bundles on import — see
  `Assets/Scripts/Game/Addons/ModSupport/ModLoaderInterfaceWindow.cs`.
- The game requires user-supplied DOS Daggerfall assets and supports a custom data path for locating them on
  device — see `Paths.cs`.
